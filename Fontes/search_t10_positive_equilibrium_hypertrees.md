# Adversarial search target: positive projected equilibria on 3-uniform hypertrees

This script exhaustively enumerates small **linear connected acyclic 3-uniform hypergraphs** generated by attaching each new clause through exactly one existing variable and two new variables. It enumerates clause polarities and boundary/interior coordinate states on a rational grid and tests the exact projected-equilibrium KKT sign conditions for the multilinear potential.

It is deliberately a **counterexample search**, not a proof. Any hit with Phi>0 refutes the proposed universal statement E_proj(K) subset {Phi=0}. No hit only guides the next symbolic lemma.

Run with Python 3.11+.

```python
from __future__ import annotations
from fractions import Fraction
from itertools import product
from collections import defaultdict

def phi_grad(edges, signs, x):
    n=max(max(e) for e in edges)+1
    phi=Fraction(0); g=[Fraction(0) for _ in range(n)]
    for e,s in zip(edges,signs):
        fac=[(1-Fraction(si)*x[v])/2 for v,si in zip(e,s)]
        p=fac[0]*fac[1]*fac[2]; phi+=p
        for q,(v,si) in enumerate(zip(e,s)):
            other=Fraction(1)
            for r in range(3):
                if r!=q: other*=fac[r]
            g[v] += -Fraction(si,2)*other
    return phi,g

def projected_equilibrium(g,x):
    # v=-g projected on T_[−1,1]^n must vanish.
    # interior: g=0; x=+1: -g >=0 is outward => g<=0;
    # x=-1: -g <=0 is outward => g>=0.
    for gi,xi in zip(g,x):
        if -1 < xi < 1:
            if gi != 0: return False
        elif xi == 1:
            if gi > 0: return False
        elif xi == -1:
            if gi < 0: return False
    return True

def canonical_attachment_trees(m):
    # rooted construction; sufficient for adversarial discovery, not
    # isomorphism-complete certification.
    edges=[(0,1,2)]
    out=[]
    def rec(es,nextv):
        if len(es)==m:
            out.append(tuple(es)); return
        vertices=sorted({v for e in es for v in e})
        for a in vertices:
            rec(es+[(a,nextv,nextv+1)],nextv+2)
    rec(edges,3)
    # remove literal duplicate edge lists
    return list(dict.fromkeys(out))

def search(max_clauses=4, grid=(Fraction(-1),Fraction(-1,2),Fraction(0),Fraction(1,2),Fraction(1))):
    for m in range(1,max_clauses+1):
        for edges in canonical_attachment_trees(m):
            n=max(max(e) for e in edges)+1
            # gauge-fix first literal of first clause to +1 to reduce symmetry
            sign_tail=list(product((-1,1), repeat=3*m-1))
            for tail in sign_tail:
                flat=(1,)+tail
                signs=[flat[3*i:3*i+3] for i in range(m)]
                for x in product(grid, repeat=n):
                    phi,g=phi_grad(edges,signs,x)
                    if phi>0 and projected_equilibrium(g,x):
                        return {"m":m,"edges":edges,"signs":signs,"x":x,"phi":phi,"grad":g}
        print("no hit through m =",m)
    return None

if __name__=="__main__":
    hit=search()
    print("HIT:",hit)
```

The sign test above follows directly from the tangent cone of the box. A positive hit must be independently verified symbolically before it is used in the manuscript.

The enumeration intentionally starts with rational grid points because multilinear stationary equations often expose symmetric rational candidates. Failure to find a grid hit is not evidence of nonexistence. The next escalation is symbolic elimination / interval certification component-by-component.
